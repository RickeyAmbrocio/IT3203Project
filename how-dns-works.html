Topic 2

How DNS Works

When someone enters a domain name into a browser, DNS helps the computer find the IP address needed to contact the website's server.

A basic DNS lookup

  1. You enter a domain name. For example, you type www.kennesaw.edu into your browser.
  2. Your device looks for the address. It checks available DNS information and sends a request to a DNS resolver if needed.
  3. The resolver finds the answer. If the answer is not cached, the resolver may query other DNS servers to locate the correct record.
  4. The address is returned. The resolver sends the IP address back to your device.
  5. Your browser connects to the website. The browser uses the IP address to communicate with the web server.

Two important DNS server roles

Recursive resolver

The resolver receives the DNS request from your device. If it does not already know the answer, it searches by asking other DNS servers.

Authoritative DNS server

This server provides official DNS records for a domain or DNS zone. A resolver can ask it for the information needed to answer a query.

Why it matters

Without DNS, people would have a much harder time using the internet because they would need to remember IP addresses instead of familiar domain names.
