Domain Names

A domain name is a human-readable name used to identify a resource on the internet. It is easier to remember a name than a long numerical address.

Parts of a domain name

Consider www.example.com. The parts have different roles:

www

This is a hostname or subdomain often used for a website. A website may use a different hostname or none at all.

example

This is the second-level domain name in this example. It is the main name registered under the ending.

.com

This is the top-level domain (TLD), which appears at the end of the domain name.

Common top-level domains

EndingCommon use or meaning
.comCommonly used by businesses and other organizations
.eduUsed by eligible educational institutions
.govUsed by eligible government organizations in the United States
.orgOften used by organizations, including nonprofits
.netOriginally associated with network-related uses; now used more broadly
.us, .ca, .jpExamples of country-code top-level domains

Remember

A domain name is not the same thing as an IP address. DNS helps find the IP address associated with a domain name.
